🎨 Design System

  • Primary Color: #0f294d (Dark Blue - Main Brand)
  • Water Gradient: #4fb3d9 to #0f7ba2 (Rivers)
  • Land Gradient: #2ecc71 to #27ae60 (Rwanda Landscape)
  • Accent Colors: #e8a87c to #d9976b (Hospitality)

📋 Implementation Guide

  • All icons are configured in app.json (Expo)
  • Web manifest available at public/manifest.json (PWA support)
  • SVG source files available for custom modifications
  • All PNG sizes generated automatically from SVG sources
  • Supports iOS, Android, Web, and PWA platforms

🔄 Regenerate Icons

To update icons after modifying SVG files:

  • npm run icons:convert - Generate main icon sizes
  • npm run icons:all - Generate all icon sizes
  • npm run icons:clean - Remove generated PNG files
